# Security Policy

## Supported Versions

Only the latest published `0.x` release of `@cablegram/server` receives security updates.

## Reporting a Vulnerability

Please report security vulnerabilities privately via GitHub Private Vulnerability Reporting on this repository or by emailing `security@cablegram.app`.

Include:
- Affected version (`server_version` from `GET /api/server`)
- A clear description of the issue and reproduction steps
- Any relevant logs or configuration details (with secrets redacted)

We aim to acknowledge reports within 72 hours and coordinate disclosure once a fix is released.
